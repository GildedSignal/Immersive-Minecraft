# Immersive Flight Camera

Client addon for the exact installed Minecraft 26.2 / AutoThirdPerson 1.0.0+26.x / Perspective API 1.5.0-beta combination. Removes the old airborne-with-elytra heuristic through a required Mixin and supplies a separate policy.

Only real fall-flying, excluding levitation and climbable blocks, starts the three-second timer. Pausing suspends the timer. Existing immediate mounted third person remains. Short flights cancel the timer. The configured Leawind perspective is selected through the Perspective Switcher behavior, preserving its 260 ms camera transition and active selection; no direct vanilla CameraType writes occur. Normal POV controls take priority for the rest of the flight. A new press of the jump binding (normally Space) toggles first/third while already gliding, without consuming flight input. The takeoff press is ignored. Space changes are flight-only: landing restores the pre-flight perspective, avoiding Leawind's ground shoulder view when the trip began in first person. A choice made through the normal POV key/wheel remains after landing.

Version 1.1 adds arrow-key steering during actual elytra gliding: Left/Right turn, Up raises the nose, and Down lowers it. Bindings appear under Elytra flight in Minecraft controls. Mouse aiming remains available. Input ramps smoothly; the existing Leawind camera gains a short follow delay, up to 16 degrees of banking, speed-dependent pullback and a modest FOV increase. The local player's body banks through turns. Eight camera collision rays constrain the adjusted position against nearby blocks. Controls are inactive outside gliding and while a screen is open, paused or unfocused. Motion settings are adjustable in `config/immersive-flight-camera.json`; existing personal settings are retained.

Build: bundled Python `build.py`. 142 policy assertions, 32 motion assertions and Java verification pass against the installed 26.2 APIs. A native copied-world test equips an elytra, enters real gliding, selects Leawind after the existing three-second delay, turns in both directions with arrow bindings, captures camera/body banking, and checks that arrows leave a nongliding player unchanged. The user previously confirmed the existing delay, Space toggle and landing restoration work. Version 1.1 is staged; installation and sharing-release packaging are pending disk space. The entrypoint and Mixins remain in separate packages, checked by the build. Removing this addon restores original AutoThirdPerson behavior.

This addon contains original MIT-licensed source and no copied Perspective API or AutoThirdPerson classes. Reference decompilations are development material, not bundled.
