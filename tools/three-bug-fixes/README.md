# Minecraft 26.2 compatibility repairs

The Recolourful Containers 3.1.4 Minecraft 26.2 text shader omitted `#define USE_RED_CHANNEL`. Its fallback `gl_VertexID % 4` corner selection broke under the current GUI renderer's batching. The animation textures already contain red-channel corner markers. `fix_ui.py` enables that existing path in one shader; every other archive entry is unchanged. Native captures reproduce repeated/triangular strips before the change and remove them afterward on Ender Chest, anvil and stonecutter probes, including preceding text and tooltips, with Faithful, Iris, Sodium and ImmediatelyFast. Artwork and animation timing are retained. The original pack is downloaded from its author; no modified Recolourful artwork is redistributed.

Interactive Stuff 0.7.0 invokes `onPlaySound` on the sound engine thread. A captured sculk-sensor script then calls `Player.playSound`, which accesses the render thread's world random source and triggers C2ME's thread-safety exception. The addon redirects off-thread sound callbacks to Minecraft's executor, with stale queued work discarded on script load/clear and connection changes. C2ME's safety check remains enabled; the previous immutable binding cache remains intact. In a copied-world native test, an actual held-sculk script receives a worker callback and plays its clicking sound on Minecraft's thread without that exception.

On servers without Field Guide, its category screen originally has no server-supplied categories. The addon loads the installed guide data locally and uses the original book, native scan completion and discovery notifications. Personal discoveries, seen entries, names, descriptions and selected variants are stored per player/server in `fieldguide_local_progress/<sha256>.json`; journals use `fieldguide_local_journals/<sha256>.json`. Writes are atomic with a previous-file backup. Personal progress packets are intercepted locally on unsupported servers. A native copied-world test loads six categories and 177 entries, completes a pig scan, saves an entry note, reloads and verifies persistence with zero outgoing Field Guide packets. Native Scholar journal typing and reopening also pass. Servers advertising Field Guide's scan channel retain upstream synchronization. Server-specific loot tables, custom server datapacks and rewards cannot be reconstructed from a client-only installation. Bad existing files are retained.

Sound Physics' direct-source shortcut previously retained indirect rays' muffling and path length, even when a chest had clear line of sight. The optional chest mixin supplies direct distance and unmuffled gain for the existing clear-path shortcut. It preserves obstructed paths, reverb, 320 rays and 12 bounces. The actual native `playMuffled` pipeline passes 21 clear-position checks and 21 stone-wall controls across single, double and Ender chests. Natural audible/overlap confirmation remains pending. Client exit also calls the mod's existing executor shutdown method; copied-world clients exit without the previous lingering-worker watchdog.

`build.py` uses Java 25 and the locally installed Minecraft/Fabric/Field Guide/Interactive Stuff/Sound Physics APIs. `test.py` runs callback ordering, stale sessions, missing worlds, player/server scope, Unicode notes, discovery persistence, backups, bounds and invalid-file retention checks (36 assertions). `runtime/run.py` creates hidden isolated before/after GUI clients with a dummy offline account, no player saves and no authentication data. Additional copied-world tests are under `tools/todo-repairs/runtime`; private saves, reports and screenshots are excluded from public source.

The addon is original MIT code. Optional mixins apply only when the corresponding upstream mod is installed, so the protected profile can also use it. The author pack archive is reconstructed from its verified original download and an archive recipe by the launcher. Release 2026.10.14.2 includes compatibility addon 1.1.0, the UI correction, the guarded Enderman atlas correction and author Streams Reflowing 2.14.4. Original production files are backed up before installation.

Upstream references: [Field Guide](https://github.com/evanbones/Field-Guide), [Interactive Stuff](https://github.com/omardotcontent/InteractiveStuff), [Recolourful Containers](https://modrinth.com/resourcepack/recolourful-containers-gui). Upstream Interactive Stuff's current source also uses main-thread dispatch for sound callbacks; the published 26.2 version remains 0.7.0.
