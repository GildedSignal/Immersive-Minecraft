# Minecraft 26.2 compatibility repairs

The Recolourful Containers 3.1.4 Minecraft 26.2 text shader omitted `#define USE_RED_CHANNEL`. Its fallback `gl_VertexID % 4` corner selection broke under the current GUI renderer's batching. The animation textures already contain red-channel corner markers. `fix_ui.py` enables that existing path in one shader; every other archive entry is unchanged. Native captures reproduce repeated/triangular strips before the change and remove them afterward on Ender Chest, anvil and stonecutter probes, including preceding text and tooltips, with Faithful, Iris, Sodium and ImmediatelyFast. Artwork and animation timing are retained. The original pack is downloaded from its author; no modified Recolourful artwork is redistributed.

Interactive Stuff 0.7.0 invokes `onPlaySound` on the sound engine thread. A captured sculk-sensor script then calls `Player.playSound`, which accesses the render thread's world random source and triggers C2ME's thread-safety exception. The addon redirects off-thread sound callbacks to Minecraft's executor, with stale queued work discarded on script load/clear and connection changes. C2ME's safety check remains enabled; the previous immutable binding cache remains intact. This repairs the captured thread violation. The separate shutdown-watchdog reports are not proven to have the same cause. A representative sculk-sensor gameplay check remains necessary.

On servers without Field Guide, its category screen has no server-supplied categories. The addon opens its existing editable journal instead, and persists notes locally per player/server in `fieldguide_local_journals/<sha256>.json` with atomic replacement and a previous-file backup. These notes are never sent to unsupported servers. Native Scholar widgets, typing, saving, unloading/reloading and reopening pass in the isolated client. Field Guide servers retain the original journal synchronization and discovery behavior. Creature scans/categories require Field Guide on the server; this fallback supplies personal notes. Bad existing journal files are retained and are not overwritten.

`build.py` uses Java 25 and the locally installed Minecraft/Fabric/Field Guide/Interactive Stuff APIs. `tests/CompatPolicyTest.java` covers callback ordering, stale sessions, missing worlds, player/server scope, Unicode notes, backups, bounds and invalid-file retention (22 assertions). `runtime/run.py` creates hidden isolated before/after clients with a dummy offline account, no player saves and no authentication data. Runtime reports and screenshots stay in the workspace.

The addon is original MIT code. Optional mixins apply only when the corresponding upstream mod is installed, so the protected profile can also use it. The author pack archive is reconstructed from its verified original download and a small archive recipe by the launcher. Local production files are backed up before installation. Release 2026.10.14.1 includes the addon and the UI correction in both profiles.

Upstream references: [Field Guide](https://github.com/evanbones/Field-Guide), [Interactive Stuff](https://github.com/omardotcontent/InteractiveStuff), [Recolourful Containers](https://modrinth.com/resourcepack/recolourful-containers-gui). Upstream Interactive Stuff's current source also uses main-thread dispatch for sound callbacks; the published 26.2 version remains 0.7.0.
