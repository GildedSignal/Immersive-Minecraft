# Interactive Stuff binding metadata cache

The 12 October profile identified repeated Java method enumeration and annotation lookup in Vyn's NativeBinder while Interactive Stuff updates held-item scripts. This patch replaces two enumeration calls in `lambda$bind$3` with immutable, class-scoped metadata caches. Per-instance script environments, host objects and changing values remain fresh. Only annotated constructors, functions and destructors are retained, in their original order. Returned arrays are cloned.

One original class is modified and three original helper classes are added. All other installed JAR entries remain byte-identical. The friend launcher reconstructs the archive from its author's verified download. Original helper and patch code uses the accompanying MIT license; upstream notices remain intact.

`NativeBinderCacheTest.java` exercises 110 assertions against both versions: state updates, separate hosts, inheritance, hidden methods, constructor names, exception propagation, destruction and repeated wrapping. A small fixture measured 33.3 versus 25.4 ms for 20,000 wraps; this is not a game FPS measurement. The live patch installed after correcting the agent's missing inner-class bundle. A later profile still executes held-item scripts, with repeated method enumeration absent and fewer annotation samples; varied scenes prevent a causal total-frame-time comparison.

`build.py` compiles Java 25 sources with ASM 9.10.1, tests both versions and stages the patched archive. Its default input is the unmodified 0.7.0 Minecraft 26.2 JAR in the author's Modrinth profile. After installation, use an original author download with `--original <jar> --jdk <JDK25-bin-folder> --asm <asm-9.10.1.jar>`; an already-patched class is deliberately rejected by the two-call-site guard. The standalone release manifest records the original URL and hash. `NativeCacheAgentV2.java` is the corrected live agent; no diagnostic agent is installed in the shared game.
